# 我的 Git 学习笔记

\## 第一次Git实验总结 

1\. git add 的作用是： 把工作区的修改，添加到暂存区，标记这些文件，准备提交。

2\. git commit 的作用是：将暂存区里已经 add的改动，提交到本地仓库，生成一条新的版本快照，附带提交信息。

3\. git restore notes.md 的作用是：用暂存区的文件覆盖工作区的 notes.md，丢弃工作区对这个文件的修改。而那些没有 add 的改动会丢失。

4\. commit 与 push 的区别是：commit是本地操作，只把改动保存到电脑上的本地 Git 仓库，不会同步到远程仓库。push是同步操作，把本地仓库已经 commit 好的版本，上传推送到远程仓库GitHub。
